# AGline for Android

Release downloads for the AGline Android app (https://agline.in): your AI agent rings your phone, and your answer goes back as text.

- Download: the latest `agline.apk` is under **Releases** (tag `latest`), with `agline.apk.sha256`.
- Verify: `shasum -a 256 agline.apk` and compare with the checksum file.
- Android asks you to allow installs from your browser once (the app is not on Google Play yet).
- This repository only hosts release files. The service and its documentation live at https://agline.in.
